# AE2 Web 中文名称与界面汉化 v1.0.0

适用 **Minecraft 1.20.1 / Forge / AE2 Web Integration 1.2.0-pre** 旧版网页。v1.0.0 是独立汉化工具的版本，不是 AE2WI 服务端 Mod 的版本。用户已在「齿轮盛宴」反馈完整名称表导入及网页显示成功。

## 已经安装旧版

只需在 Tampermonkey 中更新现有同名脚本为 `ae2web-names.user.js` v1.0.0，再刷新网页；不要同时启用两个脚本副本。原来的名称表和中文名开关会保留，无需重新导出或导入。客户端 v0.1.1 导出器可以继续使用，无需替换；v1.0.0 JAR 的全部 8 个类与它字节一致，仅更新版本元数据。

右下角面板现在默认收起。点击右侧“设置”列中的 **中文显示** 按钮展开，点击“收起”或在面板内按 Esc 关闭；刷新后保留展开状态。窄屏先展开网页的“设置”；登录页的入口位于屏幕右侧。收起面板不影响汉化。

底部作者信息栏默认隐藏，可在面板中“显示底部信息栏”，原作者和项目链接保留。界面汉化、物品中文名、底栏显示及面板展开分别控制。

## 第一次安装

1. 将 `ae2web-local-names-1.0.0-mc1.20.1-client-only.jar` **只放入本地整合包客户端的 `mods/`**，不要放到服务器。若安装过旧版导出器，退出游戏并移除旧 JAR 后再替换。
2. 保持相同的整合包、资源与脚本，切换游戏语言为简体中文，进入世界。
3. 可先把几个测试物品放进背包，运行客户端命令 `/ae2webnames sample`；完整导出使用 `/ae2webnames export confirm`。生成文件位于游戏目录 `ae2webnames/`；命令无需 OP。
4. 在浏览器安装 Tampermonkey，然后安装包内的 `ae2web-names.user.js`。已配置 `http://k.rainplay.cn:34392/` 及本机 2324 端口；用于其他地址时需调整脚本头部 `@match` 和公共主机端口限制。
5. 打开 AE2 网页，点击“中文显示”，导入 JSON 名称表，点击“开启中文名”，刷新网页。界面汉化默认开启，不依赖名称表。

名称表只保存在本浏览器，不上传服务器。脚本不改请求参数、权限或库存；无需替换服务端 JAR、重启服务器或修改存档。此发行包不包含服务端 Mod。

## 覆盖范围与验证

界面覆盖终端菜单、设置、网络选择、合成计划、CPU 状态、合成记录、登录注册及已知提示。名称需要精确匹配物品键和注册 ID；未知变体保留服务器原名，不覆盖自定义改名。完整导出不穷举所有 NBT 组合；特殊物品可放进背包后重新导出，更新整合包或汉化资源后也需重新导出。

发行构建、资源元数据检查、5 项 Java 测试、256 组官方发行 JAR 稳定键比对、16 项脚本测试及 3 项原版网页 Chromium 测试通过。浏览器测试连接本地模拟服务，覆盖下单、提交、取消、登录注册及移动端面板；不等同于完整整合包实测。外部 Chart.js 绘图未进行实际渲染测试，图表标题与提示转换有单元测试。

ZIP 内的 `SHA256SUMS` 校验内部文件；版本页单独提供的 `SHA256SUMS` 另含完整 ZIP 的校验值。源码与身份编码来源见版本标签及 `provenance.json`，许可证见 `LICENSE`。
